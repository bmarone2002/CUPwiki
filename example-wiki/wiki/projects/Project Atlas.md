# Project Atlas

## Stato attuale

Iniziativa **attiva**: costruire e mantenere la mia knowledge base personale di ricerca come LLM Wiki, usando l'agent per ingest e query e [[Obsidian]] per la navigazione.

> Nota: questa è una pagina `project` — contiene il *mio* contesto e le *mie* decisioni. I fatti pubblici sulle cose che cito (es. [[Niklas Luhmann]]) stanno nelle loro pagine `entity`, non qui. Vedi la regola "entity ≠ project" nel `CLAUDE.md`.

## Obiettivo

Smettere di perdere ciò che imparo. Ogni documento letto deve lasciare una traccia interrogabile; ogni domanda ben risposta deve diventare una pagina riusabile (filing back).

## Tesi / approccio

- Adotto lo [[Zettelkasten Method]] come disciplina di scrittura: note atomiche, fittamente linkate.
- Markdown puro + git, niente DB finché non supero ~qualche centinaio di pagine.
- Tema portante iniziale: [[knowledge-management]].
